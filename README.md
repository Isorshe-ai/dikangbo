## 🚀 Overview

This portfolio website features a premium, glassmorphic design with dark mode support, interactive animations, and a unique dual-view "About Me" section (Recruiter/Developer mode). Built with vanilla HTML, CSS, and JavaScript for optimal performance and SEO.

## ✨ Features

- **🌓 Dark/Light Mode Toggle** - Seamless theme switching with persistent preferences
- **📱 Fully Responsive** - Optimized for all devices and screen sizes
- **🎨 Glassmorphism Design** - Modern UI with frosted glass effects and smooth animations
- **⚡ Interactive Elements**
  - Typing animation effect
  - Scroll-triggered animations
  - Hover effects and micro-interactions
- **👔 Dual View Mode** - Toggle between recruiter-friendly and developer-focused content
- **📄 CV Download** - One-click resume generation in PDF format
- **🔗 Social Integration** - Direct links to GitHub, LinkedIn, and other platforms
- **📧 Contact Form** - Integrated with Formspree for easy communication

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (Vanilla), JavaScript (ES6+)
- **Fonts**: Inter, Fira Code (Google Fonts)
- **Icons**: Font Awesome 6.4.0
- **PDF Generation**: html2pdf.js
- **Deployment**: Netlify
- **Version Control**: Git & GitHub

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- Optional: Local web server for development

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Isorshe-ai/dikangbo.git
   cd dikangbo
   ```

2. **Open locally**
   - Simply open `index.html` in your browser, or
   - Use a local server:
     ```bash
     # Python 3
     python -m http.server 8000
     
     # Node.js (with http-server)
     npx http-server
     ```

3. **View in browser**
   ```
   http://localhost:8000
   ```

## 🎨 Customization

### Update Personal Information

Edit `index.html` to update:
- Name and title
- About me content
- Skills and technologies
- Project details
- Experience timeline
- Contact information

### Modify Styling

Edit `style.css` to customize:
- Color scheme (CSS variables in `:root`)
- Fonts and typography
- Animations and transitions
- Layout and spacing

### Enhance Functionality

Edit `script.js` to modify:
- Typing animation text
- Theme toggle behavior
- Scroll animations
- Form handling

## 📝 Configuration

### Contact Form Setup

Replace the Formspree endpoint in `index.html`:

```html
<form action="https://formspree.io/f/YOUR-FORM-ID" method="POST">
```

Get your form ID from [Formspree](https://formspree.io/).

### Social Links

Update social media URLs in the "Let's Connect" section:

```html
<a href="https://github.com/YOUR-USERNAME" target="_blank">
<a href="https://linkedin.com/in/YOUR-PROFILE" target="_blank">
```

## 🌐 Deployment

### Deploy to Netlify

1. Push your code to GitHub
2. Visit [Netlify](https://netlify.com)
3. Click "New site from Git"
4. Select your repository
5. Deploy!

Your site will be live at `https://your-site-name.netlify.app`

### Deploy to GitHub Pages

```bash
# Enable GitHub Pages in repository settings
# Select branch: master
# Your site will be available at: https://username.github.io/dikangbo
```
